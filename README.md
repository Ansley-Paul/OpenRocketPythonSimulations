Monte Carlo method for 1 stage and 2 stage model rockets.
- Download jar file from here: https://github.com/openrocket/openrocket/releases/tag/release-23.09 
- Download Java SE Development Kit 21.0.7 from here: https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html 

In %appdata% make sure to add a ThrustCurves folder under OpenRocket if not already there, and add the ENG files to that folder.
